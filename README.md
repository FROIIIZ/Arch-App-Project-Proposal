# **Requirements**
Java JDK 8 or later
Git
##Installation

**Clone the repository:**
```
git clone https://github.com/FROIIIZ/Arch-App-Project-Proposal
```
**Enter the project folder:**

```
cd Arch-App-Project-Proposal
```
**Compile**

Compile the Java program with:

```
javac TDEEApp.java
```
**Run**

Run the program with:
```
java TDEEApp
```
# **How It Works**
Start the application.
Create a profile by entering your information.
The application calculates your estimated BMR and TDEE.
Log your meals by entering the meal name and calories.
Select whether the meal is a Food or Drink.
View your remaining calories and meal history.
